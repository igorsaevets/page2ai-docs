## Igor Saevets

Independent AI expert and founder of **Page2AI** — the Chrome extension, MCP server, and npm library that convert any web page into clean Markdown for large language models. All three products are open source under the MIT license and run locally with zero telemetry.

Igor's work sits at the intersection of browser tooling, LLM context engineering, and open web standards. Page2AI is the first product in a planned suite of composable, privacy-preserving tools that reduce token cost and hallucination for AI agents that consume live web content.

## What Igor works on

- **Page2AI** — Chrome extension + MCP server + `@page2ai/core` npm library. Author, maintainer, sole contributor.
- **AI tooling for the LLM ecosystem** — small, composable pieces that fit the "Unix philosophy" — one job well, no telemetry, MIT license, deterministic output.
- **Research** — a technical whitepaper on DOM-position-aware tab-widget deduplication for LLM context extraction is in progress. A US provisional patent covering the underlying method is planned.
